## Student Collaboration Platform (PHP + MySQL)

### Setup (XAMPP)
- Start **Apache** + **MySQL** in XAMPP.
- Open phpMyAdmin and import `database.sql` (or run it in the SQL tab).
- Visit `http://localhost/student_collab/`

### What’s included
- Auth: `register.php`, `login.php`, `logout.php`
- Projects + join requests: `pages/project.php`
- Tasks per project: `pages/task.php`
- Files per project: `pages/files.php`
- Chat (1:1): `pages/chat.php`
- Student directory: `pages/students.php`
- Profile edit + avatar upload: `pages/profile.php`
